**件数行の書式に注意。** `node --test` の要約は **`ℹ tests / ℹ pass / ℹ fail`** で、TAP の `# fail` ではない。
`grep '^# fail'` は**常に空振りする**（前セッションが詳細を捨てたのと同じ形の罠）。
**ログは丸ごとファイルに落としてから grep する**（`| tail` に通すと件数行ごと消える）。
