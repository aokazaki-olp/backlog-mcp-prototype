## 独立性について

- **他視点の結論を渡さない。** 各 `L*.md` にはその視点自身の指摘しか書いていない
- 統合者が閉じた指摘を渡すのは、**蒸し返し防止のための意図的な妥協**（スキル本体が認めている）
- **却下・保留も渡してある。** 覆してよいが、理由を示すこと

## 第2巡で何を見てもらうか

各 `L*.md` に3つ書いてある。

1. **解消の検証** — 「修正済み」と主張されているものが本当に閉じたか。
   **部分的 / 場所が移っただけ / 症状は消えたが根は残っている**を見分ける
2. **二次被害** — **修正そのものが新しい欠陥を作っていないか。これが再レビューの主目的**
3. **新規** — 第1巡で見落としたもの

**台帳の状態列は全件「未決」のまま**にしてある。**解消の判定はレビュー側の仕事**であって、
直した側が触るものではない、という運用。第2巡の報告を受けて統合者が状態を確定させる。
